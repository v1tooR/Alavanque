Tabela de dados — ficha técnica, comparativos, moldes. Cabeçalho em caixa-alta, linhas com hover azul-claro.

```jsx
<Table
  columns={[{key:'attr',label:'Especificação'},{key:'val',label:'Valor',align:'right'}]}
  rows={[{attr:'Altura',val:'60 cm'},{attr:'Peso',val:'32 kg'},{attr:'Capacidade',val:'5 litros'}]}
/>
```

Use `striped` para tabelas longas.
